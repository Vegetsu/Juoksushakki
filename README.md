# Juoksushakki
Juoksushakki-sovellus, joka on tehty erikoistyötoteutuksena Itä-Suomen yliopistolle.

Juoksushakin toimintaperiaate on seuraava: kaksi pelaajaa valitsevat omat pelinappuloidensa värit, jonka jälkeen peli alkaa. Kun peli alkaa, niin molemmat pelaajat lähtevät juoksemaan valitun pituisen matkan, joka voi kulkea esimerkiksi jonkun rakennuksen tai muiden esteiden ympäri. Matka tulee kuitenkin aina päättymään takaisin tietokoneen luokse. Tietokoneessa on yhdistettynä kaksi nappia ja yksi hiiri, ja pelaajien täytyy painaa omaa nappiansa saadakseen pelivuoron itselleen. Kun pelaaja on lunastanut pelivuoronsa, niin hän saa tehdä yhden siirron shakkilaudalla. Pelaaja valitsee hiirellä mitä pelinappulaa hän haluaa liikuttaa ja tekee halutun siirron hiirellä klikkaamalla, minne hän sen haluaa siirtää. Vuoro loppuu automaattisesti siirron onnistuttua. Kun siirto on tehty, niin pelaaja lähtee juoksemaan uudestaan samaa matkaa ja saa tehdä seuraavan siirtonsa taas tultuaan pelilaudan luo. tätä prosessia toistetaan, kunnes toinen pelaaja voittaa. Tällä juoksumekaniikalla pyritään siihen, että toinen pelaaja voi saada enemmän siirtoja aikaiseksi kuin toinen pelaaja, näin mahdollisesti antaen esimerkiksi huonommalle shakkipelaajalle mahdollisuuden voittaa, jos hän on parempi juoksemaan kuin toinen pelaaja.
